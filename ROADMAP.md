# Project roadmap

The [README roadmap](README.md#roadmap) is the canonical overview of current priorities. The [roadmap tracking issue](https://github.com/Josh-Archer/terraform-provider-seerr/issues/360) links the implementation issues, dependencies, and completion criteria.

Work is grouped into three [GitHub milestones](https://github.com/Josh-Archer/terraform-provider-seerr/milestones): release confidence, safe adoption, and compatibility maintenance. Milestones describe sequencing rather than promised release dates.

Join [GitHub Discussion #161](https://github.com/Josh-Archer/terraform-provider-seerr/discussions/161) to propose changes or discuss priorities.
