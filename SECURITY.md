# Security Policy

We take the security of `terraform-provider-seerr` and our users' infrastructure seriously.

---

## 🛡️ Supported Versions

We provide security updates and patches for the following versions:

| Version Line | Supported |
| :--- | :--- |
| `0.38.x`+ (Current) | ✅ Yes |
| `< 0.38.0` | ❌ Upgrade Recommended |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability in this provider, please **do not report it via public GitHub issues**.

Instead, please report vulnerabilities privately:

1. **GitHub Security Advisory**: Use GitHub's private vulnerability reporting feature on this repository ([Report a vulnerability](https://github.com/Josh-Archer/terraform-provider-seerr/security/advisories/new)).
2. **Direct Email**: Alternatively, email the maintainer at `jarcher32@gatech.edu` with the subject `[SECURITY] terraform-provider-seerr`.

### What to Include
- A clear description of the vulnerability and affected resources/data sources.
- Step-by-step reproduction instructions or a minimal proof-of-concept configuration.
- Any potential impact on Seerr instances or Terraform/OpenTofu state files.

### Response Timeline
- **Initial Response**: Within 48 hours.
- **Fix & Advisory**: We will work to investigate, patch, and cut a signed release promptly.
