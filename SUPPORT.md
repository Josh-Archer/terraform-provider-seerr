# Getting Support for `terraform-provider-seerr`

Welcome! Here is where and how to get help when managing Seerr / Jellyseerr / Overseerr with OpenTofu or Terraform.

---

## 💬 Community Q&A & Discussions

For general questions, configuration help, module patterns, or feature ideas:
- **[GitHub Discussions](https://github.com/Josh-Archer/terraform-provider-seerr/discussions)**: The primary place to ask questions, share homelab snippets, and connect with other users.

---

## 🐛 Reporting Bugs

If you have found a bug or unexpected behavior:
1. Check existing [GitHub Issues](https://github.com/Josh-Archer/terraform-provider-seerr/issues) to avoid duplicates.
2. Open a new issue using our **[Bug Report Form](https://github.com/Josh-Archer/terraform-provider-seerr/issues/new?template=bug_report.yml)**.
3. Please include your provider version, OpenTofu/Terraform version, Seerr server version, and redacted HCL snippets.

---

## 💡 Proposing Features

Have an idea for a new resource, data source, or helper?
- Open a **[Feature Request Form](https://github.com/Josh-Archer/terraform-provider-seerr/issues/new?template=feature_request.yml)**.
- For new upstream endpoints, use the **[Upstream API Sync Form](https://github.com/Josh-Archer/terraform-provider-seerr/issues/new?template=upstream_sync.yml)**.

---

## 🗺️ Project Roadmap

To see what features and milestones are currently in progress or planned for upcoming releases:
