# Consumer replay: arr-config

Sanitized copy of the `seerr_*` resources used by the consumer repo's
`terraform/arr-config` root module. It is run by
`scripts/test-consumer-replay.sh` (CI job `consumer-replay`) against a
disposable Seerr container:

1. fresh `tofu apply` with the provider under test, then
   `tofu plan -detailed-exitcode` must exit 0;
2. `tofu apply` with the previously released provider, upgrade to the provider
   under test, then `tofu plan -detailed-exitcode` must exit 0.

All hostnames, URLs and credentials are test values. Provider requirements are
generated by the script and are not part of this directory. When the consumer
changes how it uses the provider, update this copy.
